# Student Learning Portal

## Introduction

The Student Learning Portal is a project related to education. It is about helping students find useful learning materials and learn new things.

## About the Project

I created this project to practice writing a README file using Markdown. It contains information about the project, some useful links, an image, and an example of HTML code. Learning becomes *interesting* when we try new things, and **practice** helps us improve. ~~Learning is only about books~~ Learning is also about exploring and trying new things.
